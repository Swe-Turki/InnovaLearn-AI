System overview

About the project

InnovaLearn-AI is derived from "Innovation" and "Learn" — an AI-driven educational platform built to bridge gaps in modern e-learning, especially for Arabic-speaking students and educators. It integrates real-time transcription, multilingual translation, intelligent chatbots, OCR, quiz generation, and learning analytics in one unified system.

Developed as a Bachelor of Software Engineering graduation project at Umm Al-Qura University, College of Computing, supervised by Dr. Ahmed Alharthi, 2026.

Features

F-1
User profile

Register, login, update profile, and manage accounts securely with role-based access.

F-2
Lecture transcription

Speech-to-text for live and recorded lectures. Students can save priority-tagged notes.

F-3
Lecture translation

Arabic ↔ English translation for live sessions and recorded transcripts.

F-4
Multilingual UI

Full RTL (Arabic) and LTR (English) interface with smooth one-click language switching.

F-5
Quiz system

AI-generates MCQ, True/False, and essay questions from documents. Manual editing supported.

F-6
Learning analytics

Tracks performance, strengths, and weaknesses. Provides visual progress reports for educators.

F-7
AI chatbot

Answers academic questions, summarizes lectures, and helps educators generate slides.

F-8
OCR

Extracts editable text from uploaded images. Supports export to .txt files.
